# 1С:Предприятие — учебное портфолио

Репозиторий содержит учебные и практические работы, выполненные в рамках обучения разработке на платформе **1С:Предприятие 8.3** в АНО ДПО «МУЦ ИТ».

Здесь представлены результаты выполнения учебных заданий, разработки прикладных конфигураций и освоения основных механизмов платформы.

## Структура репозитория

### 1. [course-assignments](projects/course-assignments/)

Практические задания курса «1С программист».

Включает две самостоятельные учебные конфигурации:

- **Подсистемы** — результаты выполнения заданий № 1–5.
- **Отчёты** — отдельная конфигурация, подготовленная для выполнения задания по разработке отчёта.

Для обеих конфигураций представлены DT-выгрузки и XML-исходники.

### 2. [mini-uchet-prodazh](projects/mini-uchet-prodazh/)

Сквозное практическое задание по разработке учебной конфигурации для автоматизации учёта продаж товаров и услуг.

В проекте рассматриваются справочники, документы, регистры, отчёты, печатные формы, управляемые формы, подсистемы и разграничение прав доступа.

Подробнее — в [описании проекта](projects/mini-uchet-prodazh/README.md).

## Используемые технологии и механизмы

- **Платформа:** 1С:Предприятие 8.3.
- **Язык программирования:** встроенный язык 1С (BSL).
- **Работа с данными:** справочники, документы, перечисления, константы и регистры.
- **Отчётность:** система компоновки данных (СКД).
- **Интерфейс:** управляемые формы, подсистемы и командный интерфейс.
- **Печатные формы:** табличные документы и макеты.
- **Администрирование:** роли и права доступа.

## Форматы материалов

В репозитории используются два формата выгрузки:

- **DT** — выгрузки информационных баз, предназначенные для восстановления учебных баз в 1С:Предприятии.
- **XML** — выгрузки конфигураций, позволяющие изучать структуру метаданных и программные модули.

## Учебный контекст

**Учебное заведение:** АНО ДПО «МУЦ ИТ».

**Направление:** разработка на платформе 1С:Предприятие.

**Курс:** «1С программист».
