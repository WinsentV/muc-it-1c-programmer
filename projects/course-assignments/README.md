# Учебные задания курса «1С программист»

Практические работы, выполненные в рамках курса **«1С программист»** АНО ДПО «МУЦ ИТ» на платформе **1С:Предприятие 8.3**.

## Описание

В данном разделе представлены результаты выполнения учебных заданий курса, объединённые в две самостоятельные конфигурации.

Каждая конфигурация представлена в двух форматах:
- **DT** — выгрузка информационной базы, позволяющая восстановить учебную базу в 1С:Предприятии.
- **XML** — выгрузка конфигурации для изучения структуры объектов, метаданных и программных модулей.

## Состав работ

### 1. Учебная конфигурация — «Подсистемы»

Основная учебная конфигурация, содержащая результаты выполнения заданий № 1–5.

В рамках этой работы последовательно выполнялись практические задания по разработке и настройке конфигурации 1С:Предприятие.

**Материалы:**
- `dt/УчебнаяКонфигурация_СЗ_1СП_26_1_Задание5_Подсистемы.dt`
- `xml/subsystems/` — XML-выгрузка конфигурации.

### 2. Учебная конфигурация — «Отчёты»

Самостоятельная конфигурация, подготовленная специально для выполнения задания по разработке отчёта.

Работа выполнялась на основе чистой конфигурации: сначала в неё загружались необходимые данные, затем реализовывалось задание по формированию отчёта.

**Материалы:**
- `dt/УчебнаяКонфигурация_СЗ_1СП_26_1_Задание5_Отчеты.dt`
- `xml/reports/` — XML-выгрузка конфигурации.

## Форматы и структура материалов

| Каталог | Содержание |
|---|---|
| `dt/` | Выгрузки двух учебных информационных баз |
| `xml/subsystems/` | Исходники конфигурации «Подсистемы» |
| `xml/reports/` | Исходники конфигурации «Отчёты» |

## Используемые технологии

- 1С:Предприятие 8.3.
- Конфигуратор 1С.
- Встроенный язык 1С (BSL).
- Метаданные и объекты конфигурации.
- Подсистемы и командный интерфейс.
- Механизмы разработки отчётов.
