# МиниУчетПродаж

Учебный проект по разработке прикладной конфигурации на платформе **1С:Предприятие 8.3** в рамках курса «1С программист» АНО ДПО «МУЦ ИТ».

## Описание проекта

«МиниУчетПродаж» — учебная конфигурация, предназначенная для автоматизации основных операций по учёту продаж товаров и услуг.

Проект разработан в рамках сквозного практического задания курса. Разработка выполняется последовательно, с применением различных механизмов платформы 1С:Предприятие.

## Функциональные возможности и содержание

### 1. Нормативно-справочная информация

- Справочники валют, контрагентов и номенклатуры.
- Перечисление типов номенклатуры: товар и услуга.
- Константы для хранения названия организации и валюты учёта.

### 2. Учёт продаж

- Документ «Реализация товаров и услуг».
- Табличная часть с номенклатурой, количеством, ценой и суммой.
- Автоматический расчёт сумм при изменении количества и цены.
- Автоматическое заполнение валюты документа.
- Получение актуальных цен из регистра сведений.

### 3. Формы и пользовательский интерфейс

- Программное управление видимостью элементов форм.
- Обработка клиентских и серверных событий.
- Подсистема рабочего места менеджера.
- Начальная страница приложения с быстрым доступом к основным операциям.
- Настройка командного интерфейса.

### 4. Регистрация хозяйственных операций

- Регистр сведений «ЦеныНоменклатуры».
- Регистр накопления «Продажи» (вид — обороты).
- Регистр накопления «Взаиморасчёты» (вид — остатки).
- Формирование движений документа по нескольким регистрам.

### 5. Аналитическая отчётность

- Отчёт «АнализПродаж».
- Использование системы компоновки данных (СКД).
- Получение данных из виртуальной таблицы оборотов регистра накопления.
- Группировка данных по контрагентам и номенклатуре.

### 6. Печатные формы

- Формирование накладной с помощью конструктора печати.
- Разработка макета акта оказания услуг.
- Программное заполнение табличного документа.
- Вывод итоговой суммы прописью.

### 7. Разграничение прав доступа

- Роль «МенеджерПоПродажам».
- Роль «Администратор».
- Настройка прав чтения, редактирования и доступа к объектам конфигурации.

## Используемые технологии и механизмы

- 1С:Предприятие 8.3.
- Встроенный язык 1С (BSL).
- Язык запросов 1С.
- Объектная модель платформы.
- Управляемые формы.
- Клиент-серверное взаимодействие.
- Регистры сведений и накопления.
- Система компоновки данных (СКД).
- Табличные документы и макеты.
- Роли и права доступа.

## Материалы проекта

- `dt/` — выгрузка информационной базы в формате DT.
- `xml/` — выгрузка конфигурации в XML для изучения структуры объектов и программных модулей.
